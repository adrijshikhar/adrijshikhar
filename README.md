## 👤 For humans

I build real-time data infrastructure — Change Data Capture (CDC), streaming runtimes, and the distributed control planes behind them. Chemical engineering graduate from IIT Roorkee, software systems ever since. Exploring the intersection of data infrastructure and agentic AI.

### Featured Systems & Scale

- **Binlog V2 (Debezium MySQL CDC)** — Architected and rolled out Hevo's next-generation MySQL CDC engine, powering 100% of production MySQL ingestion pipelines.
- **Hermes Control Plane** — Built the core orchestration plane for Hevo 2.0 managing distributed pipeline lifecycles and state transitions (`Java 17` · `Dropwizard` · `Temporal`).
- **High-Throughput Scaling** — Scaled pipelines to sustain **25,000+ source objects** while optimizing metadata queries to drop API latency from **60s → sub-second**.
- **Production Reliability** — Resolved **200+ P0/P1** distributed systems incidents and shipped **1,889 PRs** across 47 repositories.
